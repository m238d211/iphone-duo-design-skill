# New iPhone Duo screen workflow

1. Name the primary task, active scene/window context, and target framework.
2. Resolve horizontal and vertical size classes and local container constraints independently.
3. Choose a system navigation/container model and define primary, detail, and supporting pane roles only when space supports them.
4. Query/use runtime safe and reserved regions; do not transfer Figma guide values into code.
5. Define folded behavior: what displaces, what may scroll across a division, and what must stay reachable.
6. Preserve task flow, selection, input, and scroll state across a presentation transition.
7. Check Dynamic Type, VoiceOver, Reduce Motion/Transparency, contrast, RTL, localization, and keyboard/focus.
8. State source IDs, community references, and any unresolved assumptions in the result.
